# 제품 범위

[목차](../requirements.md)

## 서비스

**단축번호와 가족 안내로 조회·모의 송금을 수행하는 고령층 금융 서비스.**

| 사용자 가치 | 제공 방법 |
| --- | --- |
| 업무를 쉽게 찾기 | 번호 누르기·말하기 |
| 송금 내용 확인 | 내 계좌 → 받는 사람·계좌 → 금액 |
| 필요한 안내 받기 | 큰 글씨, 다시 듣기, 전체 안내 보기 |
| 송금 재확인 | 고액·단시간 반복 송금 안내 |
| 가족 안내 개선 | 자주 쓰는 업무·안내 검토 단계 확인, 문구·녹음 수정: D-02 |

## 역할

| 역할 | 업무 | 이용 범위 |
| --- | --- | --- |
| 주 사용자 | 조회·송금·설정·전화 | 고령 사용자 중심 |
| 가족 설정자 | 패턴·사람·계좌·안내 관리, 분석 확인 | 같은 기기·로그인 세션 |
| 보호자 | 이상거래 상황에서 전화 연락 | 연락처 한 개, 원격 승인 없음 |
| 시연 운영자 | 당일 모의 자료·연동·검증 준비 | 별도 관리자 화면 없음 |

## 용어

| 용어 | 의미 |
| --- | --- |
| 단축번호 | 1–12번과 금융 패턴의 연결 |
| 패턴 | 업무·이름·설명·연결 계좌·단계·안내 설정 |
| 시작 안내 | 실행 전 확인창의 설명·음성 |
| 단계 안내 | 특정 단계의 문구·AI/가족 음성 |
| 내 계좌 | 조회·출금에 쓰는 모의 본인 계좌 |
| 받는 계좌 | 등록 사람 또는 직접 입력한 상대 계좌 |
| 등록 사람 | 이름·관계와 하나 이상의 받는 계좌 |
| 가족 음성 | 가족이 직접 녹음한 안내 |
| 단계 방문 | 단계 진입부터 이탈까지. 재진입은 새 방문 |

## 기능 범위

| 포함 | 제외 |
| --- | --- |
| 카카오 로그인·세션·선택 동의·접근성·모의 계좌 준비 | SMS/비밀번호 회원가입·로그인 PIN |
| 기본 8개·최대 12개 패턴, 번호·업무 음성 입력 | 자유 대화·음성만으로 송금 확정 |
| 사람별 복수 계좌, 기본 내 계좌, 보호자 연락처 | 별도 보호자 앱·기기 연결·원격 승인 |
| 등록/직접 송금, 잔액·거래·연금·관리비·공과금·고객센터 | 실제 은행·결제망·마이데이터 연동 |
| 단계 안내·AI 음성·가족 녹음·패턴 내 편집 | 음성 복제·모델 학습 |
| 고액·반복 FDS, 계속·취소·전화·카톡 시연 | 자동 차단·추가 FDS 조건 |
| 동의 기반 기록·분석·문구 개선 | 건강·인지 평가, 카드·자동이체·예금만기·환율 |

- 카톡 버튼은 보호자 표현을 사용하되 실제 시연 대상은 본인 계정.
- 음성 미리 생성: [D-03 선택 검토](design-decisions.md).
