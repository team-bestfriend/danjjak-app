# 남은 결정·선택 기능

[설계 상태와 변경 ID](../specs/requirements/design-decisions.md)

| ID/항목 | 상태 | 본선 판단·영향 |
| --- | --- | --- |
| D-01 | 화면 설계안 | 질문을 유지하는 접이식 안내 기본안, 시간 경과 자동 표시는 미정 |
| D-02 | 화면 설계안 | 많이 쓴 업무·안내 검토 단계의 활용 목적과 배치 확인 |
| D-03 / FR-061 / CH-13 | 선택 검토 | 실제 기기에서 지연·무효화·실패 비교 후 채택. 필수 개발·Epic 완료를 막지 않음 |
| D-04 / CH-08·10·23 | 표현·자산 선택 | AI 음성 호칭·글꼴·아이콘·은행 로고, 한국어 청취와 사용 가능 자산 확인 |
| D-05 | 순서 설계안 | 직접 송금의 한 화면 한 입력은 확정, 구체 순서는 기본안을 검토 |
| Figma·참고 UI·image.png | 미제공 | 승인된 구체 배치·자산으로 간주하지 않음 |
| 대회 사전 반입 | 주최 측 확인 없음 | 선언만 있는 Java가 허용된다고 표시하지 않음. 프로젝트의 설계 작성 범위와 구분 |

- 고정 범위: 네 탭, 번호 인식 후 기존 확인창, 카톡 보호자 표시/본인 수신 시연, 단일 계좌도 확인, 직접 입력 단계 분리, 숫자·한글 금액.
- D-01·02·04·05는 담당 필수 이슈의 설계 검토 항목이며 별도 승인 절차가 아닙니다. D-03만 선택 평가 이슈로 분리합니다.
- 현재 설계 준비 범위를 바꾸는 미결정 사항은 없습니다. 실제 연동 자격정보·기기 검증은 해당 본선 이슈의 준비 조건입니다.
