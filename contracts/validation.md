테스트에서 `voiceMode=null` 상속이 enum 제약에 막히는 문제를 발견해 명시적으로 null을 허용하도록 수정했습니다. 경고의 위험 수준과 사유 수, 패턴 송금의 등록 계좌 분기도 스키마로 검증합니다.

## 미실행 범위

- Spring Controller/DTO/mapper 구현, Tomcat API 실행, 실제 FE 이관 코드의 타입/필드 변경 및 연동 검증.
- MySQL DDL·Flyway·모의 자료 실행, SQL/FK 동작·락·롤백·동시 제출/중복 방지 검증.
- 실제 카카오 로그인/메시지, TTS 제공사, 마이크 녹음·파일 저장소·실기기.
- SC-001–018의 앱 실행 검증. 여기의 스키마 테스트는 실제 금융·기록 원자성이나 제공사 성공을 증명하지 않습니다.

#11은 공동 계약·물리 모델·종료 책임의 구현 기준을 제공하는 범위입니다. #12는 작업 도중 PR #44로 닫혔으나, 확인한 구현은 Spring 초기 설정·문자열 health 응답까지입니다. DB 준비 및 health 계약 일치는 #13과 연결해 보완하고 FE 적용은 #42 및 해당 기능 이슈에서 진행합니다. 시나리오별 담당은 [범위 연결](coverage.md)을 따릅니다.
