# HTTP 계약 준비

[아키텍처 입출력](../docs/specs/requirements/architecture.md)을 기반으로 본선에 `contracts/openapi.yaml`을 작성합니다. 현재 경로·필드·상태 코드·실행 가능한 계약은 확정하지 않습니다. 먼저 사람/계좌·안내 대상 식별, 독립 동의, 부분 저장 재시도, 실제 선택 내 계좌, 금융/방문/실행 최종 확정 책임을 정하고 FE·BE가 같은 계약을 사용합니다.
