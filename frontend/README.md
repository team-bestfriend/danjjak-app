# 프론트엔드 준비

Vue 3·Vite·Pinia·Vue Router로 화면을 구성합니다. `src/views`, `api`, `components/common`, `composables`, `features`, `stores`, `router`, `constants`에 화면·통신·공통 요소·상태·탐색 책임을 나눕니다.

현재 화면·자바스크립트·패키지 설정은 없습니다. [공통 UX](../docs/specs/requirements/shared-ux.md)와 담당 이슈에서 필요한 파일만 구현합니다.
